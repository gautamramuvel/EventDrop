# EventDrop Demo Script

## 0:00 - Product Context

EventDrop is a 24-hour neighborhood event board for spontaneous local discovery.

## 0:30 - Browse

Open live URL. Show All Events without signing in. Filter by category, time window, and distance.

## 1:15 - Create

Sign in with test credentials. Create a new event inside launch zone with duration and optional capacity.

## 2:00 - RSVP

Open event detail. RSVP. Show headcount update and explain reminder queue creation.

## 2:45 - Reminder

Trigger reminder endpoint in test mode or show Supabase `event_reminders` row status.

## 3:30 - Report/Admin

Submit report. Open admin review page. Explain auto-hide after three reports.

## 4:15 - Architecture

Summarize Vercel, Clerk, Supabase PostGIS, Supabase Cron, and Resend trade-offs.
